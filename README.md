# Doctor AI Companion 🩺🧠

Doctor AI is an advanced, interactive AI Life Simulator and Personal Assistant app built using Flutter. It features a smart companion capable of switching roles, learning from the internet, managing offline data, and adapting to different virtual environments.

## 🚀 Features Implemented
- **Dynamic Environments:** Toggle instantly between the **Laboratory** and the **Virtual Kitchen** or **Chill Lounge**.
- **Context-Aware Outfits:** Automatic wardrobe updates based on current tasks (Doctor Scrubs, Chef Uniform, or Casual Wear).
- **Time & Weather Windows:** Simulated time of day and environmental context changes inside the visual monitor.
- **Smart Activity Logger:** Live operational routine tracker that shows background states and task status.
- **Vibe & Sync Mode:** Background multi-language music queue option that alters the active context of the companion.

## 📱 Getting Started

### Prerequisites
- **Flutter SDK:** `>=3.0.0 <4.0.0`
- **Dart SDK**
- An Android device or emulator for testing.

### Automated Builds via GitHub Actions
This project includes a pre-configured CI/CD workflow (`.github/workflows/main.yml`). Every commit to the `main` branch triggers an automated build that generates a fresh downloadable APK artifact directly within GitHub Actions.

## 📂 Project Structure
- `main.dart`: Contains the central code for the interactive graphical interface.
- `.github/workflows/`: Holds the automation deployment script for compiling the mobile applications.
